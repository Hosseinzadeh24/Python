# ربات معامله‌گر رمزارز (Crypto Trading Engine)

یک موتور معاملاتی ۲۴ ساعته برای رمزارزها شامل: دریافت داده، تحلیل تکنیکال و آماری، مدل‌های یادگیری ماشین و یادگیری عمیق (scikit-learn)، مدیریت ریسک، معامله کاغذی (paper) و معامله واقعی (live)، هشدار فرصت، کالیبراسیون هفتگی با گزارش نموداری، و یک برنامه اندروید برای نمایش وضعیت.

## ⚠️ مهم: این بخش را حتماً بخوانید

- **هیچ ربات و هیچ مدلی سود تضمین‌شده نمی‌دهد.** رمزارز بازاری پرریسک است و امکان زیان کامل سرمایه وجود دارد. عددهای ۱۰٪ و ۱۵٪ هفتگی «هدف گزارش‌دهی» هستند، نه وعده.
- **حالت پیش‌فرض معامله کاغذی (`mode: paper`) است.** معامله واقعی فقط با تنظیم صریح `mode: live` و متغیر محیطی `BOT_LIVE_CONFIRM=I_ACCEPT_RISK` فعال می‌شود.
- نتایج هر کالیبراسیون باید روی **داده واقعی** و برای **چند ماه** بررسی شود، نه یک هفته. یک هفته سود مثبت، شانس بالایی ندارد که تصادفی نباشد.
- ربات را با سرمایه کم شروع کنید و قبل از هر سرمایه بزرگ، حداقل چند هفته معامله کاغذی را ببینید.

## آنچه پیاده‌سازی شده

| بخش | فایل | توضیح |
|---|---|---|
| داده | `crypto_bot/data.py` | خواندن CSV، دریافت کندل‌های عمومی از صرافی با ccxt، داده مصنوعی برای تست |
| ویژگی‌ها | `crypto_bot/features.py` | بازده‌ها، میانگین متحرک (SMA/EMA)، MACD، RSI، باند بولینگر، ATR، نوسان، حجم، Z-score، ساعت شبانه‌روز |
| مدل‌ها | `crypto_bot/models.py` | گروه مدل: رگرسیون لجستیک (آماری-احتمالاتی)، Gradient Boosting، شبکه عصبی MLP. خروجی: P(بالا رفتن قیمت) |
| ریسک و اندازه پوزیشن | `crypto_bot/risk.py` | Kelly کسری (۲۵٪ کلی)، سقف هر کوین، ارزش انتظاری خالص پس از کارمزد |
| شبیه‌ساز | `crypto_bot/backtest.py` | کارمزد، لغزش قیمت، حد ضرر و سود (ATR)، زمان‌بند خروج، محدودیت زیان روزانه، کلید توقف با افت سرمایه. سیگنال روی بسته شدن کندل، اجرا روی باز شدن کندل بعد (بدون نگاه به آینده) |
| کالیبراسیون | `crypto_bot/calibration.py` | Walk-forward: هر هفته، پارامترها فقط با داده‌های آموزش/اعتبارسنجی انتخاب می‌شوند؛ سپس هفته بعد، بدون دیدن آن، معامله می‌شود |
| گزارش | `crypto_bot/report.py` | نمودار هر دوره (ربات در برابر خط پایه SMA و خرید-و-نگهداری)، نمودار خلاصه، نمودار مقایسه اجراها |
| اجرای ۲۴ ساعته | `crypto_bot/bot.py` | حلقه مداوم، بازآموزی روزانه مدل، ذخیره وضعیت، توقف خودکار در خطا |
| معامله | `crypto_bot/broker.py` | `PaperBroker` (شبیه‌سازی) و `LiveBroker` (ccxt، با قفل ایمنی) |
| هشدار | `crypto_bot/alerts.py` | هشدار فرصت با احتمال و سود انتظاری بالا، در کنسول/فایل و در صورت تنظیم، تلگرام |
| اندروید | `mobile/` | برنامه Kivy برای نمایش وضعیت، پوزیشن‌ها و هشدارها |
| CI | `.github/workflows/` | تست خودکار و ساخت APK با buildozer |

### مدل‌های نام‌برده شده (DeepSeek، Claude، ChatGPT، Copilot، GLM، Gemini و …)
این‌ها مدل‌های زبانی (LLM) هستند و برای پیش‌بینی قیمت آموزش ندیده‌اند. اجرای آن‌ها برای هر تصمیم معاملاتی هزینه و تأخیر دارد و پاسخ‌هایشان قابل تکرار نیست. به‌جای آن، روش‌های شناخته‌شده کمی (آماری، ML، DL) پیاده شده‌اند. اتصال یک مدل زبانی برای تحلیل خبر (sentiment) می‌تواند در مرحله بعد اضافه شود، ولی به‌عنوان تأیید فیلتری، نه منبع تصمیم خودکار.

## نصب

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json   # تنظیمات را ویرایش کنید
python -m pytest -q tests            # تست‌ها
```

## دستورها

```bash
# 1) نمایشی با داده مصنوعی (فقط برای دیدن خروجی)
python -m crypto_bot calibrate --source synthetic --periods 4

# 2) کالیبراسیون واقعی با داده عمومی صرافی (۴ هفته، هر هفته ۷ روز)
python -m crypto_bot calibrate --source ccxt --periods 4

# 3) اجرای کد زنده روی داده تاریخی (تست مسیر اجرا)
python -m crypto_bot replay --source synthetic --bars 2400

# 4) حلقه ۲۴ ساعته (پیش‌فرض: معامله کاغذی)
python -m crypto_bot run

# 5) سرور وضعیت برای برنامه اندروید
export BOT_STATUS_TOKEN="یک-رمز-طولانی"
python -m crypto_bot serve-status --port 8080
```

## کالیبراسیون و هدف ۱۰٪ / ۱۵٪

- هر دوره ۷ روزه (۱۶۸ کندل ساعتی). مدل روی ۶۰ روز گذشته آموزش می‌بیند.
- پارامترها (آستانه ورود/خروج، فاصله حد ضرر و سود، زمان نگهداری) از شبکه‌ای کوچک انتخاب می‌شوند. معیار انتخاب فقط روی ۲۵٪ انتهای داده آموزشی سنجیده می‌شود.
- هفته‌ای که گزارش می‌شود، **برای انتخاب پارامتر دیده نمی‌شود**. بنابراین بازده گزارش‌شده یک برآورد خارج از نمونه است.
- نمودار `charts/period_N.png` بازده ربات، خط پایه SMA و خرید-و-نگهداری را نشان می‌دهد. `charts/summary.png` هدف ۱۰٪ و ۱۵٪ را خط‌چین سبز نشان می‌دهد.

**چرا حلقه‌ای که «تا رسیدن به ۱۰٪ تنظیم کند» پیاده نشده؟** اگر پارامترها تا جایی تغییر کنند که هفته تست به هدف برسد، همان هفته دیگر تست مستقل نیست و عدد نهایی به‌طور مصنوعی خوب دیده می‌شود (overfitting). ادامه دادن این کار تا ۱۵٪ هم همین مشکل را دارد. روند درست این است که کالیبراسیون روی داده‌های زیاد و جدید اجرا شود و خروجی گزارش‌شده مبنای تصمیم باشد.

## اجرای ۲۴ ساعته روی سرور

برای اجرای مداوم، ربات باید روی یک سرور (VPS لینوکسی) اجرا شود. گوشی اندروید برای این کار مناسب نیست، زیرا سیستم‌عامل برنامه‌های پس‌زمینه را متوقف می‌کند.

```bash
sudo mkdir -p /opt/crypto-bot && sudo cp -r . /opt/crypto-bot && cd /opt/crypto-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
sudo cp deploy/crypto-bot.service deploy/crypto-status.service /etc/systemd/system/
# /opt/crypto-bot/.env شامل کلیدهای صرافی؛ هرگز در گیت نگذارید
sudo systemctl daemon-reload && sudo systemctl enable --now crypto-bot crypto-status
```

کلیدهای API صرافی را فقط با دسترسی **Spot Trading** و **بدون Withdraw** بسازید.

## برنامه اندروید (APK)

APK با buildozer در GitHub Actions ساخته می‌شود (`.github/workflows/build-apk.yml`). در تب Actions روی **Run workflow** بزنید؛ فایل `crypto-monitor-apk` را دانلود کنید و روی گوشی نصب کنید (نیاز به فعال‌کردن نصب از منابع ناشناس). در برنامه، آدرس `http://SERVER:8080/status` و توکن را وارد کنید.

> این APK نمایش‌دهنده وضعیت است. موتور معاملاتی روی سرور اجرا می‌شود. اگر بخواهید موتور روی خود گوشی اجرا شود، سیستم‌عامل آن را در پس‌زمینه متوقف می‌کند.

## هشدار فرصت

اگر مدل برای یک کوین احتمال بالا رفتن `alert_min_prob` (پیش‌فرض ۷۰٪) و سود انتظاری خالص پس از کارمزد `alert_min_net_edge` (پیش‌فرض ۳٪) را بدهد، هشدار در `data/alerts.jsonl`، کنسول و در صورت تنظیم `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` در تلگرام ارسال می‌شود. هشدار فقط یک پیشنهاد است و معامله خودکار جداست. ربات در آن‌ها همچنان طبق قوانین ریسک عمل می‌کند.

## کنترل ریسک

- سقف هر کوین: ۲۵٪ سرمایه تخصیص‌یافته؛ Kelly کسری ۲۵٪.
- زیان روزانه بیش از ۳٪: ورود جدید تا پایان روز UTC بسته است.
- افت کل ۱۵٪: توقف دائمی و بستن پوزیشن‌ها (تا وقتی دستی بازنشانی نشود).
- هر ورود فقط اگر ارزش انتظاری خالص پس از کارمزد و لغزش مثبت باشد.
- فایل `data/STOP` حلقه را متوقف می‌کند.

## محدودیت‌های شناخته‌شده

- معاملات فقط خرید-فروش اسپات (بدون اهرم و شورت).
- مدل‌ها روی داده تاریخی آموزش می‌بینند؛ بازار می‌تواند رژیم عوض کند و مدل از کار بیفتد.
- ۱۰٪ و ۱۵٪ هفتگی با نوسان بالای رمزارز و کارمزد، به‌طور مداوم و مطمئن قابل دستیابی نیست.
- `LiveBroker` روی صرافی واقعی تست نشده است؛ قبل از استفاده، با مبلغ بسیار کم و در حالت کاغذی/تست صرافی بررسی کنید.
